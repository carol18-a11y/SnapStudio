# SnapStudio

A modern web-based photobooth application built with **Python**, **Flask**, and **OpenCV** that allows users to capture photos directly from their webcam through a simple and responsive web interface.

This is the **Level 1** version of the project, focusing on core camera functionality and laying the foundation for future features like filters, photo strips, and AI-powered effects.



## Features

- Live webcam preview
- Capture photos with a single click
- Save captured images
- Download photos
- Clean and responsive user interface
- Lightweight and easy to use


## Tech Stack

| Technology | Purpose |

| Python     | Backend |
| Flask      | Web Framework |
| OpenCV     | Webcam & Image Processing |
| HTML5      | Structure |
| CSS3       | Styling |
| JavaScript | Client-side Interactions |
